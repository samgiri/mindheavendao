# Assumptions

These assumptions enable documentation only and are not approved protocol decisions:

- BNB Smart Chain is the first deployment target, with portable EVM interfaces.
- OpenZeppelin-style audited primitives are available and will be independently reviewed.
- HEAVEN is a separate token and will be specified before reward implementation.
- No reward liability is created without sufficient HEAVEN funding.
- Founder reference contribution values are not on-chain USD formulas.
- Contribution evidence and sensitive personal information remain off-chain.
- Launch administration uses a multisig and timelock before progressive transfer to governance.
- “Monthly” pool periods require exact timestamp boundaries and timezone-independent UTC definitions.
- Legal, tax, consumer, token, referral, privacy, and wellness reviews precede launch.
- No production contract, token distribution, node sale, or reward program is authorized by these documents.
